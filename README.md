## Dawn-wander

### プロジェクトの説明:

このプロジェクトは学校の授業である「研究」の一環で作成及び開発を進めているリポジトリとなります。

研究テーマは「アニメーションによる意識誘導」です。

プロジェクト内に三つの疑似webサイトを三種類のアニメーションで用意、それを管理するページを作っており、計10種類のサイトをこのリポジトリで開発しております。

### 技術スタック:

Frontend:React.js[HTML,CSS,Javascript]

Backend:ASP.NET[C#]

Detabase:Mysql

Serverside:ubuntu
